# React E-Commerce Website

This is a simple e-commerce website built using React. Users can view products, search for items, filter products by category, sort them by price, and manage their cart.

## Features

* Display products from the DummyJSON API
* Search products by name
* Filter products by category
* Sort products by price (low to high and high to low)
* View product descriptions
* Add products to the cart
* Increase or decrease product quantity
* Remove products from the cart
* Navigate between the product page and cart page

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* Axios
* React Router DOM

## API Used

Product data is fetched from the DummyJSON API.

https://dummyjson.com/products

## Getting Started

Clone the repository:

```bash
git clone https://gitlab.com/candyx3/react-ecom.git
```

Open the project folder:

```bash
cd react-ecom
```

Install the dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Open the local URL shown in the terminal to view the website.
